Put your media files in this folder:

  stroke.mp4      the story video (played on the TV during the game)
  srilanka.mp4    (optional) only if the host setting "Home screen shows" = Video.
                  Normally the TV home screen shows the slideshow instead.
  stroke_en.vtt   English subtitles
  stroke_ta.vtt   Tamil subtitles
  stroke_si.vtt   Sinhala subtitles

Optional explanation pictures / clips (shown after each question):
  q1.jpg, q2.png, q7.mp4 ...  (q + question number)
The game finds them automatically. You can also type any file name in
"media" in questions.json.
